# 🏡 Análisis de Asequibilidad de Vivienda y Alquileres (FY26)

Este repositorio contiene un caso de estudio completo basado en los datos oficiales de Alquileres Justos de Mercado del HUD (FY26 FMRs). El proyecto demuestra un flujo de trabajo analítico dual utilizando **Python (Pandas, Matplotlib)** y **SQL (MySQL Workbench)** para la limpieza, filtrado, agregación y visualización de datos inmobiliarios y demográficos.

---

## 🛠️ Tecnologías y Herramientas Utilizadas
* **Python:** Jupyter Notebooks, Pandas, Matplotlib
* **SQL:** MySQL Workbench (Agregaciones, filtrado condicional y funciones de ventana)
* **Visualización:** Gráficos estadísticos de distribución de precios

---

## 📊 Principales Hallazgos (Métricas Nacionales)
* **Studio (Fmr 0):** $1,014.91 USD
* **1 Habitación (Fmr 1):** $1,089.80 USD (+7.38%)

## 📂 Estructura del Repositorio
* `analisis_vivienda.ipynb`: Cuaderno principal con el código en Python y la generación de gráficos.
* `consultas_vivienda.sql`: Script con las consultas relacionales y agregaciones ejecutadas en MySQL.
* `cleaned_data/promedio_nacional_alquileres.png`: Visualización exportada de los costos promedio.
